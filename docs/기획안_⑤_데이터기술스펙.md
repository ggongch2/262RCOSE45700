# 05 데이터 · 기술 스펙

## 데이터 활용 전략 및 구성 원칙

**판정 구조**
- 후보 지점마다 합법성(도로교통법 정차 금지 여부), 물리적 가용성(정차 공간 및 뒤차 통과 폭), 승객 접근성(보도 진입 가능 여부)의 3개 조건을 순차 판정함.
- 세 조건을 모두 충족한 지점만 '가능'으로 분류하고, 값이 누락되거나 추정값인 경우 '확인 필요'로 분류하여 수동 검수 대상으로 넘김.

**데이터 역할 분담 원칙**
- 지도 데이터(좌표·도형): 시설까지의 거리, 도로 폭, 차로 수 등 정량적 위치 관계 계산 담당.
- 거리뷰 이미지: 보도 유무, 연석 단절, 노면 선 색상, 보조표지 문구 등 현장 상태 판독 담당. 노면 규제선은 지도 자료 간 일치율이 57%에 그쳐 거리뷰 판독이 필수 근거임.
- 거리뷰 활용 구조: 자동 판정은 구글 거리뷰 파일 + VLM (분석 후 삭제), 최종 확인은 운영자가 카카오 로드뷰 뷰어 링크로 최신 상태 확인. 카카오 로드뷰는 약관상 이미지 저장·추출이 금지되어 자동 판정에는 사용하지 않음.
- 사진으로 거리·폭을 측정하지 않으며, 지도로 노면 상태를 판단하지 않음. 각 데이터는 잘하는 영역에만 사용함.

## 데이터 스펙

**출처 및 라이선스**

| 구분 | 데이터 | 출처 · 이용 조건 | 활용 | 확보 현황 |
|---|---|---|---|---|
| 도로망 | OpenStreetMap 도로 선형 | 공개, ODbL (출처 표시) | 후보점 생성, 교차로 및 일방통행 판별 | 완료 |
| 시설 좌표 | 횡단보도 · 버스정류장 · 소화전 | 서울 열린데이터광장, 공공누리 1유형 | 합법성: 시설 이격 거리 산출 | 완료 |
| 시설 좌표 | 어린이보호구역 표준데이터 | 공공데이터포털, 공공누리 | 합법성: 보호구역 판별 | 10/21 예정 |
| 규제 도형 | 주정차금지선 · 정차금지지대 · 금지 표지 | 서울시 교통안전시설 관리시스템 (2021년 자료) | 합법성: 노면 규제선 판별 | 완료 |
| 도로 폭 | 지적도 도로 필지 · 정밀도로지도 차로 링크 | 국토부 VWorld API, 무료 | 물리적 가용성: 도로 폭 · 차로 수 | 완료 (정밀도로지도는 대로 한정) |
| 도로 폭 | 수치지형도 1:1000 (도로경계 · 보도 면) | 국토지리정보원, 신청제 | 보도 폭 정밀화 | 2주차 신청 |
| 거리뷰 | Google Street View Static API | 1,000장당 약 $7 (메타데이터 무료). 이미지 저장·캐시 금지, 파노라마 ID만 보관 가능 | 승객 접근성: 보도 · 연석 · 진출입로 판독 | 커버리지 실측 완료, 샘플 24장 확보 |
| 거리뷰 | Mapillary API / 카카오맵 로드뷰 | 무료 CC BY-SA / 뷰어 전용 (저장·분석 불가) | 보조 소스 / 운영자 수동 확인 화면 | 확인 완료 |

- 좌표계: WGS84로 통일. 서울시 GIS 자료(EPSG:5186)는 변환 후 사용함.

**규모 및 분할**
- 후보 지점: 강남역 반경 500m 내 도로 중심선 15m 간격 샘플링 결과 1,457개 (양측 가장자리 분리 시 약 2,900개).
- 거리뷰 이미지: 지도 단계 필터를 통과한 후보에만 요청하여 약 300장 수준으로 제한함.
- 정답셋: 팀원 직접 라벨링 100~150개 (평가 전용, 개발 중 열람 금지, 도로 유형별 층화 추출). 개발 확인용 30개, 멘토 정성 검토 20개 별도 운영.
- 학습·검증·테스트 분할 없음: 모델 학습을 수행하지 않고 VLM 제로샷 추론만 활용하므로 정답셋은 평가에만 사용함.

**라벨 정의**
- 라벨 단위: 후보 지점 1개당 판정 항목 1세트. 시스템이 자동 산출하며, 정답셋은 동일 항목을 사람이 기입함.
- 위치 항목: 좌표, 바라보는 방향(0~360°), 도로 유형, 일방통행 여부.
- 합법성 항목: 횡단보도 · 정류장 · 소화전 · 교차로까지 거리(m), 어린이보호구역 여부, 연석선 종류(백색 / 황색 점선 / 황색 실선 / 황색 복선 / 모름).
- 물리적 가용성 항목: 차로 수, 도로 폭(m).
- 승객 접근성 항목: 보도 유무, 연석 단절 여부 (2주차 사진 판독으로 확보).
- 결측 처리 원칙: 값을 모르면 null로 두며, null 또는 추정값이 포함된 지점은 '확인 필요'로 판정함. 항목명과 단위는 1주차에 확정하고 이후 추가만 허용함.
- 출력 형식: GeoJSON 점 1개 = 후보 1개. 판정(가능 / 불가 / 확인 필요), 적합도 점수, 불가 사유 목록, 항목별 체크 결과, 사진 ID, 운영자 승인·반려 메모 포함.
- 라벨링 가이드 및 검수: 부록 A 판단 기준에 따라 2인 교차 라벨링, 일치도(Cohen's κ 0.7 이상) 보고. 1주차 말 50개 파일럿 후 기준 문서 보정.

**개인정보**
- Google · Mapillary 이미지는 얼굴 · 번호판 비식별 처리 상태로 제공됨.
- 직접 촬영분은 블러 처리 후 사용하며 원본은 팀 내부 보관.
- Google 이미지는 분석 즉시 삭제하고 파노라마 ID와 결과 라벨만 저장함 (약관 준수).

**확보 일정**
- 완료 (10/16~19): 도로망, 시설 좌표, 규제 도형, 도로 폭 데이터 확보 및 강남역 구역 실측, 거리뷰 커버리지 확인, 샘플 24장.
- 1주차 내: 어린이보호구역 표준데이터 (10/21), 정답셋 50개 파일럿.
- 2주차: 수치지형도 수령, 정답셋 150개 완성, 거리뷰 약 300장 확보.

## 기술 스펙

**모델 · 알고리즘 선정**

| 역할 | 선택 | 선정 이유 |
|---|---|---|
| 지도 공간 분석 | Python geopandas · shapely · pyproj | 합법성 조건은 거리 · 반경 규칙이므로 모델 없이 결정론적 계산으로 처리 가능 |
| 사진 판독 | VLM 제로샷 (JSON 강제 출력, temperature 0). 모델은 2주차 20장 비교 후 확정 | 판독 항목이 '유무 · 색상 · 문구' 수준이라 별도 학습 불필요. 정량 측정은 지도가 담당 |
| 규칙 엔진 · 점수 | Python 조건문 (hard) + 가중합 (soft) | 규칙 10개 내외로 별도 엔진 불필요. 사유 문자열을 화면에 직접 노출 |
| 운영자 웹 | Leaflet 지도 + 카카오 로드뷰 링크, GeoJSON 저장 | 서버 없이 단일 HTML로 동작, 사용자 1명 가정 |

- 세그멘테이션 모델은 VLM 보도 판독 정확도가 미달할 경우의 예비 수단으로만 둠.

**프레임워크 및 인프라**
- Python 3.11, geopandas · shapely · pyproj, FastAPI, Leaflet. 버전은 1주차 뼈대에서 고정.
- GPU 불필요. 사진 판독은 외부 API, 지도 계산과 웹은 팀 PC 1대로 운영.

**외부 API 비용 및 제한**
- Google Street View Static: 1,000장당 약 $7, 메타데이터 무료, 이미지 저장 금지.
- VWorld (지적도 · 정밀도로지도), Mapillary: 무료, 호출 한도 내 사용.
- VLM API: 장당 약 $0.01, 분당 요청 한도 적용.
- 예상 총비용: 약 $50 (사진 300장 + VLM 호출).

**아키텍처 (카카오 안내 p.18 7단계 기준)**
1. 후보점 생성: OSM 도로망 15m 간격 샘플링, 우측 가장자리 방향 산출
2. 합법성 필터 (지도): 시설 이격 거리 · 보호구역 · 규제선 판정 → 불가 지점 사유 기록 후 제외
3. 거리뷰 확보: 통과 · 확인 필요 지점만 메타데이터로 촬영일 확인 후 이미지 요청
4. 사진 판독 (VLM): 보도 · 연석 · 노면 선 색상 · 표지 문구 · 진출입로
5. 물리 · 승객 접근 판정 및 적합도 점수 산출
6. 운영자 웹: 지도 화면 · 지점 상세 화면, 승인 · 반려, GeoJSON 내보내기
7. 검증: 정답셋 100~150개 대비 정밀도 · 재현율 산출

- 안내 자료와의 차이: 지도 필터(2)를 사진 확보(3)보다 먼저 수행하여, 탈락 지점(약 85%)의 이미지 요청을 생략함. 비용과 약관 리스크를 동시에 절감.
- 1주차 뼈대: 1 → 2 → 5 → 6 단계가 실제 데이터로 동작 중 (`scripts/pipeline_v0.py`, `web/index.html`). 사진 단계(3 · 4)는 2주차 연결 예정.

## 샘플 확보 현황 (리뷰 전 필수)

**강남역 반경 500m 실측**
- 시설: 횡단보도 137개, 버스정류장 35개, 소화전 158개, 주정차금지선 410구간, 정차 · 주차금지 표지 102개, 학교 2개 (서초초 320m, 서일중 380m).
- 거리뷰 커버리지 (후보 1,457개 기준): Google 95% (이면도로 99%, 골목 86%), 촬영 시점 2018년 중심. Mapillary 25%, 2021년 이후 사진은 테헤란로8길 1개 구간에 한정.
- 샘플 이미지 24장 확보 (대로 · 이면도로 · 골목 각 8장).

**지도 데이터 단독 판정 결과 (뼈대 v0, 10/21 기준)**
- 후보 2,440개 (양방향 도로는 방향별 우측 연석에 각 1개). 가능 4개, 확인 필요 213개 (9%), 불가 2,223개 (91%). 임시 규칙(교차로 중심 15m, 학교 반경 300m)을 '확인 필요'로 완화 시 가능 4 / 확인 필요 877 / 불가 1,559.
- 불가 사유 (중복 포함): 2021 주정차금지 구간 1,270, 학교 반경 1,073, 교차로 923, 통과 폭 부족 334, 횡단보도 256.
- 해석: 학교 반경과 교차로 규칙은 임시 규칙으로 과도하게 제외하는 상태이며, 실제 보호구역 경계와 교차로 면 적용 시 통과 지점 증가 예상. '확인 필요' 사유의 대부분은 보도 유무(사진 판독 필요). 본 수치를 ⑦ 평가의 베이스라인으로 사용함.

**규제선 자료 교차 검증 결과 (10/21)**
- 정밀도로지도가 있는 대로변 후보 477곳에서 서울시 2021 규제선 자료와 2023~25 정밀도로지도가 연석 6m 기준 **55%만 일치** (일치 183, 2021만 금지 72, 2023만 실선 75).
- 실제 사례: 테헤란로 역삼아크플레이스 앞(37.50008, 127.03476). 2021 자료에는 2017년 도색 주정차금지선 151m가 등재, 2023 정밀도로지도에는 해당 연석 규제선 없음. 2026년 카카오 로드뷰 확인 결과 연석에 황색 실선과 소화전이 실재 → 2021 자료가 맞고 정밀도로지도가 누락한 경우. 해당 소화전은 공공데이터에 40m 내 미등재.
- 조치: 두 자료가 모두 금지일 때만 불가, 불일치 시 '확인 필요'로 두고 거리뷰에서 선 색·실선 여부를 판독. 노면 규제선 판정에 거리뷰가 보조가 아닌 필수 근거임을 확인함.

**좌표 정합 실측**
- 출처 간 오차: OSM vs 서울시 횡단보도 113쌍 비교 시 중앙값 6.8m.
- 서울시 자료 간 오차: 동일 횡단보도 596쌍이 전부 6m 동일 방향 편이 → 좌표계 변환 차이로 보정 가능.
- 규제선 시점 차이: 2021년 서울시 규제선과 정밀도로지도(2023~25) 대로변 402개 지점 비교 시 81% 일치.
